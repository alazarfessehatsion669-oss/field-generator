# Release instructions

## For the person publishing this

Thank you for publishing this.

Here is what to do.

---

## Step 1 — create the repository

Create a new GitHub repository.

Suggested name:

```text
field-generator
```

Suggested description:

```text
Free music generation. Zero training. Zero cost.
```

Visibility:

- Public

---

## Step 2 — add these files

Add these files to the root of the repository:

1. `README.md`
2. `PRINCIPLES.md`
3. `ARCHITECTURE.md`
4. `WHY.md`
5. `CODE.md`
6. `field_generator.py`
7. `.gitignore`

---

## Step 3 — do not add

- a LICENSE file
- a COPYING file
- a copyright notice
- an author block
- a contributors list

This repository is intentionally published without a formal license file.

---

## Step 4 — commit

Commit message:

```text
Initial release.

Field Generator.
Free music generation.
Zero training. Zero cost.
No owner.
```

---

## Step 5 — let it stand

Do not promote aggressively. Do not ask for stars. Do not ask for contributions. Let the work stand.

If someone finds it, they find it. If someone uses it, they use it. If someone improves it, they improve it.
