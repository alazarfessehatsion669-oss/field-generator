# Principles

## The Domaine approach

This system is built on seven principles. They are not suggestions. They are the foundation.

### Principle 1 — Principle-carried
State it, carry it, return it.

Every function states what it does, carries what it needs, and returns what matters. No hidden state. No stored absolutes.

### Principle 2 — Self-revealing
Name what stands. Name what is refused.

Every module declares what it accepts and what it refuses. The boundaries are named.

### Principle 3 — Standing, not storing
No stored absolutes.

State is passed through calls, not held in globals. Nothing is remembered between runs.

### Principle 4 — Relational identity
Nothing names itself.

Every entity is defined by its relationships to other entities.

### Principle 5 — Return, then extend
Return the principle, name what is next.

Every module ends with a return value and an explicit next step.

### Principle 6 — No rank, no exception
No hierarchy beyond the principle.

No special cases. No privileged classes. Everything follows the same rules.

### Principle 7 — Two-line close
Close the loop, name the next loop.

Every module ends with:

```text
Return: <what it returns>
Next: <what comes next>
```

## How these principles apply to music

### Substrate, not container

Music is not a container of notes. Music is a substrate shaped by frequency into stable orders.

The seven orders are not stored. They are derived.

### Boundary, not hierarchy

No order is more important than another. No instrument is privileged. No genre is the default.

The boundaries are named. The hierarchy is refused.

### Carrying, not storing

The decoder does not remember. The encoder does not learn. The system does not accumulate.

Each run is fresh. Each output is derived.

### Refusal, not default

Current music-AI systems default to what they learned. Western pop. Four-chord loops. Cinderella structures.

Field Generator refuses.

Name what must never appear. It never appears.

## The physics foundation

This system rests on a simple observation:

Music is substrate shaped by frequency into seven stable orders.

- Substrate (S): the undifferentiated field
- Frequency (F): the periodic signal applied
- Boundary (B): the interface where S meets F

When F is applied to S, S resists where frequency nodes fall and moves where antinodes fall. The result is a stable geometry.

That geometry takes one of seven forms.

Every piece of music is a sequence of these orders.
